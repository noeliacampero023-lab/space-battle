🚀 Space Battle

¡Bienvenido a Space Battle! Un juego espacial en el que pilotas una nave, destruyes enemigos y consigues puntos.

🎮 Jugar online

[Haz clic aquí para jugar a Space Battle](https://noeliacampor0023-lab.github.io/space-battle/)

🕹️ Cómo jugar

- Pulsa **JUGAR** para empezar.
- Usa las flechas **← →** para mover la nave.
- Pulsa la **barra espaciadora** para disparar.
- Pulsa **ESC** para pausar la partida.
- Destruye enemigos para conseguir puntos.
- Evita los enemigos y protege tus vidas.

✨ Características

- Nave espacial controlable.
- Enemigos y disparos.
- Sistema de vidas.
- Puntuación y niveles.
- Diseño espacial con efectos visuales.
- Opción de volver a jugar.
🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub Pages
 📂 Archivos del proyecto

- `índice.html`: estructura del juego.
- `estilo.css`: diseño visual.
- `juego.js`: funcionamiento y reglas del juego.

🎯 Objetivo del proyecto

Este proyecto forma parte de mi aprendizaje de programación y desarrollo web. Mi objetivo es aprender creando un videojuego desde cero.
Su objetivo es poner en práctica mis conocimientos adquiridos mediante la creación de un videojuego sencillo, utilizando HTML, CSS y JavaScript, así como familiarizarse con herramientas como Git y GitHub.
